# Podcast App

React + TypeScript podcast SPA built as a frontend technical test, consuming the Apple Podcasts API with client-side routing and responsive UI.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Apple Podcasts API

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
